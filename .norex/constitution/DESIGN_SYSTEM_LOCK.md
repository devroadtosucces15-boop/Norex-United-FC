# Norex Design System Lock
The existing Norex visual language is the single visual authority across Web/Desktop, Web/Mobile, future iOS/Android, Norex Dev OS, and internal tools.

Extract the canonical system from the real repository; do not recreate it from memory/screenshots. Reuse tokens, typography, spacing, colors, radii, shadows, components, interaction states, responsive rules, assets, motion, and accessibility conventions.

No parallel styling system. Intentional deviations require Mike approval and an ADR.
