# Work Protocol
## Start
Read authority/constitution, MASTER_ROADMAP, relevant task/ADRs/design/context. Verify repository evidence before asserting status. Record task ownership.

## During
Preserve FE/BE/ND lanes. Record meaningful discoveries. Do not silently expand scope. Use deterministic tools for build/test/lint/typecheck. Report surface/shared-service impact. Respect cost/security/risk controls.

## Finish
Validate reported surface first. Record evidence/discoveries/handoff. Update roadmap only with evidence.

Lifecycle: BACKLOG -> READY -> IN_PROGRESS -> BLOCKED/REVIEW -> VALIDATION -> MIKE_REVIEW -> DONE.
Also: DEFERRED, SUPERSEDED, CANCELLED. DONE requires evidence.
